# RAG-Based AI Teaching Assistant

A Retrieval-Augmented Generation (RAG) based AI Teaching Assistant that answers learner questions using relevant course content instead of relying only on the language model's general knowledge.

## Features

- 🔎 Retrieves the most relevant course-content chunks for a question
- 🧠 Uses BGE-M3 embeddings for semantic search
- 📐 Uses cosine similarity to rank relevant content
- 🤖 Uses Llama 3.2 through Ollama to generate grounded answers
- ⏱️ Provides relevant video titles and timestamps
- 💬 Interactive Streamlit chat interface
- 📚 Displays retrieved course sections for transparency

## RAG Workflow

```text
User Question
      ↓
Generate Query Embedding
      ↓
Compare with Course Embeddings
      ↓
Cosine Similarity
      ↓
Retrieve Top 30 Relevant Chunks
      ↓
Build Context-Aware Prompt
      ↓
Llama 3.2 via Ollama
      ↓
Grounded Answer + Video Timestamp
```

## Installation

### 1. Clone the repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd RAG-Based-AI-Teaching-Assistant
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

If you are using the standalone `app.py` created for this project:

```bash
pip install -r requirements_app.txt
```

### 4. Install Ollama models

```bash
ollama pull bge-m3
ollama pull llama3.2
```

Make sure Ollama is running locally at:

```text
http://localhost:11434
```

You can ask questions such as:

```text

```

```text

```

```text

```

The assistant retrieves relevant course sections and uses them as context when generating the response.

## How It Works

The application first converts the user's question into an embedding using **BGE-M3**. It compares that embedding with the stored course-content embeddings using **cosine similarity**.

The highest-ranking chunks are selected as context. These chunks contain course information such as video title, video number, timestamps, and transcript text.

The retrieved context is then passed to **Llama 3.2 through Ollama**, which generates a response based on the relevant course material.

## Technical Challenge

A major challenge in a RAG system is retrieval relevance. A user may ask a question using wording that is different from the original course transcript.

The project addresses this by using semantic embeddings and cosine-similarity retrieval rather than relying only on exact keyword matching.
